1. What DevLens is

DevLens generates an AI-assisted, at-a-glance summary of a public GitHub repository: a project description, a complexity score, a risk badge, warnings, and an install guide. It is a triage aid, not a certification.

2. AI-generated content

The summary, complexity score, risk level, warnings, highlights, and install steps shown by DevLens are generated automatically by a large language model based on public repository metadata. They may be incomplete, outdated, or inaccurate. DevLens does not execute, compile, or run the analyzed code, and does not perform a manual security review. Always verify anything important directly against the source repository before relying on it.

3. Not a security or legal audit

DevLens is not a substitute for a professional security audit, a code review, or legal/compliance advice. Risk badges ("Safe", "Moderate", "Warning") reflect surface-level signals only (documentation quality, presence of tests/CI, license, activity) and are not a guarantee that a repository is free of vulnerabilities or malicious code.
