Cookie Policy

Last updated: 2026

Short version: DevLens does not set any cookies.

DevLens does not use tracking cookies, analytics cookies, advertising cookies, or session cookies. There is no login system and no per-user state to persist, so there has been no need to set any.

Local storage

DevLens does not read or write to your browser's local storage or session storage either.

Third-party resources

The page loads the Tailwind CSS library from a public CDN (cdn.tailwindcss.com) purely for styling. This is a static script resource and does not set tracking cookies on its own.

If this changes

If a future version of DevLens introduces accounts, analytics, or any other feature that requires cookies, this page will be updated to disclose exactly what is set and why, before that feature ships.
