Cookie Policy

Last updated: 2026

Short version: DevLens does not set any cookies.

DevLens does not use tracking cookies, analytics cookies, advertising cookies, or session cookies. There is no login system and no per-user state to persist, so there has been no need to set any.

Local storage

DevLens does not read or write to your browser's local storage or session storage either.

Third-party resources

The page loads the Tailwind CSS library and the Inter font from public CDNs (cdn.tailwindcss.com, fonts.googleapis.com) purely for styling. These are static resources and do not set tracking cookies on their own.

When an analyzed repository's README links to a demo video, DevLens embeds that video directly on the page (YouTube or Loom). That embedded player is loaded from the video platform's own servers and may set its own cookies under its own domain, subject to that platform's cookie and privacy policy, not DevLens's. This only happens when a video is found and displayed, and DevLens itself still sets nothing.

If this changes

If a future version of DevLens introduces accounts, analytics, or any other feature that requires cookies, this page will be updated to disclose exactly what is set and why, before that feature ships.
