DevLens

Privacy Policy

Last updated: 2026

DevLens was built as a hackathon MVP to help judges quickly assess public GitHub repositories. This page explains, plainly, what happens to the data you give it.

What you submit

The only input DevLens accepts is a public GitHub repository URL that you paste into the form on the home page. We do not require an account, a login, or any personal information to use the tool.

What DevLens does with it

  • The URL is parsed to identify the repository owner and name.
  • DevLens calls the public GitHub REST API to read that repository's already-public metadata, file listing, README, languages, license, and contributor count.
  • That signal is sent to an AI provider (Groq during development, Google Gemini in production) solely to generate the on-screen summary, complexity score, warnings, and install guide.
  • The result is returned to your browser and rendered on the page. It is not saved to a database, log file, or any persistent storage on our servers.

What we don't do

  • We don't create accounts or store personal information.
  • We don't use analytics, trackers, or advertising pixels.
  • We don't sell or share any data, because we don't retain any.
  • We don't access private repositories unless you separately configure your own GitHub token in your own deployment — the public demo only reads public repos.

Third parties involved

Analyzing a repo means DevLens talks to two external services on your behalf: the GitHub REST API (to read the repository you asked about) and an AI provider (Groq or Google Gemini, depending on configuration) to generate the written analysis. Each of those providers processes the request under their own respective privacy policies.

API keys

Server-side API keys (GitHub, Groq, Gemini) are stored only as environment variables on the server and are never exposed to your browser or included in any client-side code.

Contact

Questions about this policy can be directed to the project maintainer via the GitHub repository.
